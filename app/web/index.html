START Getting started
  1. Point ALEXIS at your data folder — pick a directory that contains (or will contain) a storage/ subfolder.
  2. Open a dashboard — the Dashboards tab lists every generated visualization in your data folder's viz/ directory.
  3. Classify a single trial — paste a title plus at least one intervention into the Classifier tab to get modality, therapeutic area, and drug-trial status.
  4. Run pipelines — the Jobs tab regenerates dashboards and classifies registry data in the background, with live logs and a cancel button.
